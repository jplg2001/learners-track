¿No conecta? Falta una regla en Firebase

El celular y el computador se hablan por un documento propio de tu cuenta. Añade este bloque en Firebase → Firestore → Reglas, junto al que ya tienes, y pulsa Publicar:

match /remotes/{uid} {
  allow read, write: if request.auth != null && request.auth.uid == uid;
}

¡Hola! Soy tu asistente de Learners Track. ¿En qué te puedo ayudar hoy con tus clases?

🔐 Configurar IA (Gemini)

Pega tu API key de Google Gemini para activar el análisis y el chat con IA en tiempo real. Si la dejas vacía, la app usa automáticamente el análisis local (sin conexión). Puedes obtener una key gratis en Google AI Studio.

🔒 Privacidad: las funciones de IA envían los datos del aula (notas, insignias y comentarios) a los servidores de Google. Con la anonimización activada, los nombres se sustituyen por alias antes de salir de este dispositivo y se restituyen solo al mostrarte la respuesta.
